SONORA — лабораторна робота №2, варіант 2 «Соніфікація даних».

**Левківський Євгеній Сергійович · ІПС-41**

[Відкрити застосунок](https://fffooocus.github.io/sonora-lab2/)

- `SONORA-lab2-IPS41.zip` — повний проєкт, вихідні файли, звіт, сценарій захисту, CSV, MIDI та перевірки.
- `report.pdf` — готовий звіт для здачі.
- `report.docx` — редагована версія звіту.
- `SHA256SUMS.txt` — контрольна сума архіву.

Для локального запуску потрібен Node.js 22+: розпакувати ZIP та відкрити «Запустити SONORA.cmd» або виконати `npm start`, потім перейти на http://127.0.0.1:4173. Додаткові npm-пакети для роботи застосунку не потрібні.

Перевірено: 26 модульних тестів, 25 браузерних перевірок; опублікований MIDI завантажується та читається незалежним парсером. CSV і формування MIDI працюють у браузері. Синтетичні приклади призначені для навчання.
