# Сценарій захисту — SONORA

Левківський Євгеній Сергійович · ІПС-41

## Демонстрація на 3–5 хвилин

1. Відкрити опублікований застосунок або виконати `npm start` і перейти на http://127.0.0.1:4173.
2. Назвати тему: лабораторна №2, варіант 2 — соніфікація даних. Показати `kyiv-weather.csv`: temperature та precipitation — два числові показники. Дані синтетичні, навчальні.
3. Пояснити: один рядок створює одну ноту. temperature → висота; precipitation → velocity та тривалість. Відкрити «Як це працює», показати формули нормалізації.
4. Натиснути Play, показати рух курсора на піаноролі, Pause, зміну позиції, Stop, гучність. Повернути гучність вище нуля, якщо її було вимкнено.
5. Змінити темп зі 108 на 120 BPM: для 24 рядків тривалість зміниться з 13,33 до 12 секунд. Обрати іншу гаму та MIDI-інструмент.
6. Поміняти показники місцями, показати нову форму мелодії. Натиснути «Енергія»: інший CSV дасть 16 нот.
7. Через «Редагувати CSV» ввести `x,y` та рядки `0,0`, `10,10`. За пентатоніки ноти — C3 й A5, velocity — 40 та 115. Невалідне значення NaN має показати помилку й зберегти попередню композицію.
8. Завантажити MIDI. Показати розширення `.mid`; за наявності відкрити в DAW або MIDI-плеєрі зі звуковим банком. На захисті можна використати готовий `examples/sonora-weather.mid`.
9. Відкрити «Матеріали роботи», завантажити PDF/DOCX. Показати вихідний код, тести та протокол браузерних перевірок.

## Короткі відповіді

- Що таке соніфікація? Перетворення даних на звук за визначеними правилами; воно дає змогу почути структуру й зміни даних.
- Чому MIDI? Він зберігає команди нот, силу, час та інструмент, а не готову звукову хвилю. Компактний та редагований у музичних програмах.
- Навіщо два показники? Це вимога варіанта: у нас один керує pitch, другий — velocity та duration, тобто разом трьома параметрами.
- Що при однакових значеннях? Нормалізоване значення 0,5; ділення на нуль не відбувається.
- Чому 480 PPQ? Це роздільна здатність часової сітки: 480 ticks на чвертну ноту. Вона не залежить від BPM.
- Що з від’ємними значеннями? Min–max нормалізація підтримує їх без окремого зсуву користувачем.
- Що означає velocity? Сила натискання MIDI-клавіші, 1–127 для звучної Note On; тут 40–115. Вона часто впливає на гучність і тембр.
- Чому дві доріжки? Перша містить метадані темпу та розміру, друга — мелодію. Це SMF Type 1, а не двоголосна композиція.
- Чи змінює гучність MIDI? Ні. Регулятор гучності керує локальним прослуховуванням. Дані velocity MIDI визначає другий показник.
- Чи враховано реальні інтервали між датами? Ні. Один рядок = одна чверть; порядок рядків збережено.
- Чому браузер і зовнішній плеєр звучать інакше? У браузері простий осциляторний синтез, зовні — тембр General MIDI зі звукового банку.
- Як перевірено правильність? Модульні тести плюс незалежний парсер midi-file; браузерні сценарії перевіряють імпорт, програвання, налаштування та скачаний файл.

## Команди

```sh
npm ci
npm test
npm run test:browser
npm run docs
npm run build
npm start
```

Для перевірок браузера на Linux/macOS спочатку `npx playwright install chromium`. У Windows автоматично використовується встановлений Edge або Chrome; за потреби задайте `BROWSER_PATH`. Для запуску готового застосунку без тестів достатньо Node.js 22+ та `npm start`; npm-залежності під час роботи застосунку не використовуються.
